Inspector del Event Ledger

El Event Ledger registra, para cada IOC que el Hub procesa, el intento de entrega a cada destino: a que destino se mando, con que politica, en que estado quedo (entregado, reintentando, dead-letter, etc.) y cuando se actualizo por ultima vez. Usa este buscador para responder "¿que paso con este IOC/evento?" -- por ejemplo, pegando un stix_id de OpenCTI para ver a que destinos se distribuyo y si llego bien a todos.

Ejemplo: buscar por destino "fortinet-edl" y estado "dead_letter" muestra que IOCs de ese destino estan fallando ahora mismo -- desde ahi, "Linea de tiempo" abre el detalle completo de ese evento.

Limite conocido (no bug): el buscador solo filtra por event_id/stix_id/destino/estado/fecha, los campos que el ledger ya guarda hoy. Todavia no se puede filtrar por family/subtype/valor del IOC porque eso requiere un Canonical Event Store aparte (ver spec/PROJECT-MAP.md).
